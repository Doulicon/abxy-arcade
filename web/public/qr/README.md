# 二维码图片放置说明

把收款码 / 联系二维码图片直接放进本目录（`web/public/qr/`），**无需改代码**。
重新构建（`npm run build`）后即可生效，浏览器按下列路径访问。

## 命名规则（文件名必须完全一致）

| 用途 | 文件名（放在本目录） | 页面访问路径 | 出现在哪 |
| --- | --- | --- | --- |
| 捐赠 / 赞赏收款码 | `donate.png` | `/qr/donate.png` | ① 顶栏「捐赠」按钮悬停弹层 ② 底部栏第三个码位 |
| 联系微信二维码 | `contact-wechat.png` | `/qr/contact-wechat.png` | 底部栏第一个码位 |
| 联系支付宝二维码 | `contact-alipay.png` | `/qr/contact-alipay.png` | 底部栏第二个码位 |

## 说明

- 支持 `png` / `jpg` / `webp` 等格式，但**文件名要与上表一致**（例如用 `donate.png`）。
  如果你只有 `.jpg`，请把文件名改成 `donate.png`，或者直接改成对应扩展名并同步告诉开发者。
- 图片**自适应大小与比例**：代码用 `object-contain` 等比缩放，不会拉伸变形，也不会定死尺寸。
- 推荐尺寸：收款码约 **400×400** 或更大、清晰即可；长宽比任意。
- 未放置的图片，对应位置会显示占位提示文字，不会出现破图。

## 底部栏三个码位顺序（从左到右）

1. 微信（`contact-wechat.png`）
2. 支付宝（`contact-alipay.png`）
3. 赞赏（`donate.png`）
